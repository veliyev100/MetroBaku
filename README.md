# BakuMetro Project

## 1. Сборка статической библиотеки

Для сборки **статической библиотеки** выполните следующие шаги:

1. Перейдите в корневую директорию проекта:

   ```bash
   cd BakuMetro_project
   ```
Создайте и перейдите в каталог для сборки:
```bash

mkdir build
cd build
```
Выполните команду для сборки:

    cmake .. -DBUILD_SHARED_LIBS=OFF
    make

2. Сборка динамической библиотеки

Для сборки динамической библиотеки выполните следующие шаги:

    Перейдите в корневую директорию проекта: 
    
    cd BakuMetro_project

Создайте и перейдите в каталог для сборки:
```bash
mkdir build
cd build

```
Выполните команду для сборки:

    cmake .. -DBUILD_SHARED_LIBS=ON
    make

  
3. Запуск проекта

После сборки проекта выполните следующую команду для запуска:
```bash
./Metro__Baku
```

4. Описание исходных файлов

    MetroBaku.h — Заголовочный файл, который содержит описание всех необходимых функций и переменных для работы с симуляцией метро.

    MetroBaku.cpp — Реализация функций, которые описывают поведение поездов на разных линиях метрополитена.

    main.cpp — Основной файл, где создаются и запускаются потоки для каждого поезда.

5. Описание функций

В проекте используются следующие функции для симуляции движения поездов:

    RedmetroTrain — Симулирует работу поездов на красной линии.

    PurplemetroTrain — Симулирует работу поездов на фиолетовой линии.

    GreenmetroTrain — Симулирует работу поездов на зеленой линии.

    LightgreenTrainMetro — Симулирует работу поездов на светло-зеленой линии.

Каждый поезд выполняет круговой маршрут по заданным станциям с остановками и ожиданием на каждой станции.
6. Описание переменных

    travel_time — Время в пути между станциями.

    stop_time — Время остановки на станции.

    turnaround_time — Время поворота поезда на конечной станции.

    train_start_delay — Задержка перед стартом поезда.

    max_round — Количество кругов для каждой линии (красной, фиолетовой, зеленой и светло-зеленой).
